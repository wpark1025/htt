# 한컴타자연습 모듈 조사 (2026-10-24)

출처: 나무위키 한컴타자연습 문서군(97, 윈도우판, 2007, 2010, 2010/게임, 2010/점수체계, 2022), 위키백과, 한컴타자 공식 지원 페이지.
실행 파일 역분석은 하지 않았다. 이 문서는 우리 앱의 모듈 설계 참고용이다.

### 자리 연습 8구역 (한글 두벌식, 현행 공식)

1. 기본 자리: ㅁ ㄴ ㅇ ㄹ / ㅓ ㅏ ㅣ ;
2. 왼손 윗자리: ㅂ ㅈ ㄷ ㄱ (Shift: ㅃ ㅉ ㄸ ㄲ)
3. 왼손 아랫자리: ㅋ ㅌ ㅊ ㅍ
4. 가운데 자리: ㅅ ㅎ / ㅠ ㅛ ㅗ ㅜ (양손 검지 뻗기)
5. 오른손 윗자리: ㅕ ㅑ ㅐ ㅔ (Shift: ㅒ ㅖ)
6. 오른손 아랫자리: ㅡ , . / (Shift: < > ?)
7. 전체 자리
8. 숫자 자리 (윗줄 + 숫자패드)

구버전(2007~2010)은 7단계 쌍자음, 8단계 ㅒㅖ였고 2022에서 전체자리·숫자자리로 교체. 2007은 7단계에서 ㅆ 미출현 버그.

1. a s d f / j k l ;  2. q w e r  3. z x c v  4. t g b / y h n  5. u i o p  6. m , . /  7. 전체  8. 숫자

## 3. 게임 규칙

### 침략자 (도스)
스페이스 인베이더. 단어 대열이 좌우로 움직이며 내려옴. 맨 아래 흰 단어부터 차례로 입력. 하나라도 바닥에 닿으면 종료.
단어 수: 1~3단계 30, 4~6단계 40, 7~9단계 50, 10~14단계 60. 하늘색 단어 효과: 다음 놀이마당, 빠르게, 천천히, 앞으로 앞으로, 잠깐만(8~10초 정지), 되살리기, 처음부터, 안보이지(6.5초 감춤).

### 산성비 (도스 2.0~97)
떨어지는 단어 입력. 놓치면 pH 감소, 0이면 종료. 단계당 단어 24 + 2×단계. 하늘색 단어는 입력 안 해도 페널티 없고 pH 1칸 회복.
점수: 기본 10점, 한글 (글자수+1)×10, 영문 홀수 (글자수+1)×5 / 짝수 (글자수+2)×5, 보너스 1000.

### 산성비 (윈도우 2.0/96, 환경 테마)
숲/바다/집 배경이 12구역. 맞은 구역 산성도 2단계 상승, 4단계면 완전 오염되어 그 구역엔 단어가 더 안 나옴. 그림이 모두 파괴되면 종료.
특수 단어 색: 빨강 = 화면 단어 전부 제거, 녹색 = 자연 복구, 파랑 = 잠시 정지.
점수: 한글 20×글자수 + 10×판수, 영문 10×(글자수+판수). 판당 단어 30 + 2×판수.

### 클레이 사격 (윈도우 2.0/96 전용)
하늘로 날아가는 글쇠 하나를 눌러 떨어뜨림. 왼손 키는 왼→오, 오른손 키는 오→왼으로 이동. 판당 20글쇠, 입력 제한 3초 → 0.7초. 놓침/오타 누적 18개면 종료. 2.0은 시작 전 글쇠 자리 선택 가능.
**입문자 첫 게임으로 가장 적합. 자리 연습 직후 단계.**

### 산성비 (2007)
1~15단계, 단계당 30단어, 단어당 단계×10점(길이 무관). 파란 단어 효과: 감추기(5초), 빠르게(5초), 느리게(빠르게 해제), pH 회복(7.0). 15단계는 클리어 불가 킬스크린.

### 자원캐기 (2007)
고정 대열 단어를 컴퓨터와 경쟁해서 더 많이 치면 승리. 1~13단계, 단계당 39단어(홀수라 무승부 없음). 11단계 이상은 10단계 클리어 필요.

### 케이크 던지기 (2010)
로봇 발밑 단어를 쳐서 처치. 체력 3칸. 1~20단계, 1·3·5·7만 직접 선택. 배경: 오븐/개수대/과자상자/냉장고/식탁.
로봇: B(속도2, 1방, 피해 0.5, 10점), R(속도1, 3방, 피해1, 20점), P(속도3, 1방, 피해1, 30점), 보스 볼트(컵케이크 7방, 40점), 보스 팡(13방, 60점).
아이템: 하트(체력+1, 40점), 일반 케이크(공격 3배 5회, 40점).

### 해상구조 SOS (2010)
1:1 대전(NPC 또는 온라인). 튜브 8칸 쌓아 헬기에 닿으면 승리. 방어: 일반 튜브 0.5칸, 비행기 튜브 1칸, 거북이(침몰 4초 느림). 공격: 상대 튜브 -0.5, 안대(3초 가림), 어뢰(침몰 4초 빠름). 맵: 태평양/뉴욕/남극/이집트/서울.

## 7. 한메타자교사 3.05 실측 (2026-10-25)

사용자가 준 `HTT_DB_Setup.exe`(MarShall의 2012년 DOSBox 번들: 한글타자 2.0, 한컴타자연습 97, 한메타자교사 3.00/3.02/3.04/3.05)를
풀어서 DOSBox Staging으로 직접 실행하고 화면을 확인했다. 우리 앱은 이 3.05의 기능을 따른다. 데이터 파일은 조합형(Johab) 인코딩.

### 흐름
타이틀 → 이름 입력(처음만) → 인사말(Space) → 글쇠 익숙 정도(처음/조금) → 작업 선택(게임/메뉴에서 시작) → 메뉴 막대.
메뉴 막대는 좌우 화살표로 메뉴, 상하로 항목, Enter로 실행. 메뉴 막대에서 ESC는 프로그램 종료. 오른쪽 위에 노란 아날로그 시계. 아래에 안내 상태줄.

### 메뉴
- 한메: 사용자 바꾸기 / 사용자 지우기 / 환경 설정 / 화면 배경 바꿈 / 끝
- 자리익힘: 기본 자리 / 왼손 윗줄 / 검지 자리 / 오른손 윗줄 / 왼손 밑줄 / 오른손 밑줄 / 왼손 쌍자음 / 기타 한글 / 숫자 / 기호 (각 "익힘")
- 낱말익힘: 단계 목록은 익힌 만큼만 열린다 (처음엔 기본 자리, 왼손 윗줄)
- 문장연습: 단문 연습 / 장문 연습 / 연습장 / 타자 검정 / 타자검정 결과
- 게임: 베네치아 / 베네치아 줄거리 / 낱말맞추기
- 통계: 글쇠 학습 상황 / 속도 / 정확도 / 화일로 보내기
- 도움말: 타자 교사란 / 손가락 기본위치 / 프로그램 사용법

### 화면
- 자리익힘: 제목 "기본 자리 익힘", 가운데 상자에 글쇠 하나, 3D 자판(기본 자리 8키는 빗금), 자판 아래 손가락 삼각형 8개(칠 손가락만 검게). 안내 "네모 속에 들어 있는 글쇠를 누르세요!"
- 낱말익힘: 먼저 그 단계 글쇠 드릴, 이어서 "학습 글쇠: ㅁㄴㅇㄹㅓㅏㅣ;" 아래 낱말 줄(어린이 미리 어머니 엄마 어머나 이랑)을 받아쓴다. 속도(타수/분) 게이지 최고/현재, 정확도 %.
- 단문 연습: 속담 한 줄, 아래 줄에 받아쓰기, 틀린 자리 위에 빨간 ↓. 게이지 동일. ESC → "연습을 계속합니다 / 메뉴로 갑니다".
- 장문 연습: 문장 고르기(제목 + 바이트 수) → 글이 한 줄 건너 표시되고 사이 줄에 받아쓴다.
- 타자 검정: 글 고르기 → "연습시간은 3분이고 감타수는 5입니다" → 남은시간 표시 → 결과: 총 타수, 정 타수, 오 타수, 유효 타, 연습 시간, 속도, 정확도.
- 베네치아: 바다 위 벽돌탑, 탑 위 입력 상자, 하늘에서 낱말이 떨어짐, "단계: 1 점수: 0". 시작 전 대화상자 "게임을 시작합니다 / 점수를 봅니다 / 단계 조정 하기", 점수판은 순위·이름·종류·단계·점수·일자 10줄. 줄거리는 타자기 효과로 흐르는 글.
- 낱말맞추기: 퍼즐 선택(제1~8단계) → 8×8 격자, 오른쪽에 커서 칸의 가로열쇠/세로열쇠. 화살표로 이동, 글자 입력.
- 통계: 글쇠 학습 상황은 기간(1~24)별 속도 꺾은선(0~500), 속도는 자모별 막대(오늘/평균), 정확도도 자모별.
- 도움말 손가락 기본위치: 자판 그림에 기본 글쇠 8개 검게, 설명문.
