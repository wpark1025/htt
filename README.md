# HTT 타자교사

한글 · 영어 타자 연습 웹앱. 1990년대 DOS 프로그램 **한메타자교사 3.05**의 기능을 그대로 다시 만들고, 겉모습은 현대적으로 바꿨습니다.
앱 언어(메뉴·안내문)와 연습 자판(한글/영어)을 따로 고를 수 있어 처음 키보드를 잡는 아이부터 어른까지 같은 앱으로 연습합니다.

- 설치 없음. 브라우저에서 바로 실행되는 정적 사이트 (서버 없음, 기록은 기기에만 저장)
- 한글(두벌식), 영어(QWERTY) 자판. 다른 언어를 추가할 수 있는 구조
- 앱 언어 한국어 / English
- 순수 교육용. 광고, 로그인, 결제 없음

배포: https://wpark1025.github.io/htt/

## 개발

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 에 정적 파일 생성
npm test         # vitest (오토마타, 단계·낱말 데이터, 퍼즐, 화면 흐름)
```

## 기능 (한메타자교사 3.05 메뉴 구성 그대로)

| 메뉴 | 항목 | 상태 |
|---|---|---|
| 홈 | 사용자 바꾸기·지우기, 환경 설정, 화면 배경 바꿈 | 완료 |
| 자리익힘 | 10단계 (기본 자리 → 왼손 윗줄 → 검지 자리 → 오른손 윗줄 → 왼손 밑줄 → 오른손 밑줄 → 쌍자음/대문자 → 기타 → 숫자 → 기호). 화면 자판과 손가락 표시 | 완료 |
| 낱말익힘 | 단계까지 배운 글쇠로만 만든 낱말을 받아쓰기. 최고/현재 속도 게이지, 정확도 | 완료 |
| 문장연습 | 단문(속담), 장문(긴 글 고르기), 연습장(자유 입력), 타자 검정(제한 시간, 오타 감점, 등급), 검정 결과 | 완료 |
| 게임 | 베네치아(떨어지는 낱말, 물 차오름, 단계·점수판·단계 조정), 베네치아 줄거리, 낱말맞추기(십자말풀이) | 완료 |
| 통계 | 글쇠 학습 상황(회차별 속도 그래프), 글쇠별 속도, 글쇠별 정확도, 파일로 보내기 | 완료 |
| 도움말 | 타자 교사란, 손가락 기본위치, 프로그램 사용법 | 완료 |
| 처음 시작 | 인사말 → 이름 → 글쇠 익숙 정도 → 시작할 곳 | 완료 |

원작 조사 기록은 [docs/modules.md](docs/modules.md)에 있습니다.

## 설계 원칙

- **한글 입력은 직접 조합합니다.** 운영체제 IME에 의존하지 않고 물리 키 위치(`KeyboardEvent.code`)를 받아
  두벌식 오토마타로 글자를 만듭니다. 한/영 전환키를 신경 쓸 필요가 없고, 어떤 키를 눌러야 하는지
  화면 자판에 정확히 표시할 수 있습니다.
- **언어는 데이터입니다.** 자판 배열, 단계, 낱말, 속담, 긴 글, 퍼즐은 `src/data/<lang>/`에, UI 문자열은 `src/i18n/`에 있습니다.
- **낱말은 배운 글쇠로 거릅니다.** 단계별 낱말은 손으로 고른 목록과 일반 낱말 목록에서 그 단계까지 배운 글쇠만으로
  칠 수 있는 것을 자동으로 골라 씁니다. 게임은 낱말 수준(1~5) 설정으로 조절합니다.
- **빌드 결과는 어디서든 열립니다.** 호스팅된 URL은 물론, 단일 HTML 파일로도 동작하게 유지합니다.
