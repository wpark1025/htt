# HTT 타자연습

한글 · 영어 타자 연습 웹앱. 1990~2000년대 한컴타자연습의 구성을 다시 만듭니다.
단어 수준과 게임 속도를 설정으로 조절할 수 있어 처음 키보드를 잡는 아이부터 어른까지 같은 앱으로 연습합니다.

- 설치 없음. 브라우저에서 바로 실행되는 정적 사이트 (서버 없음, 기록은 기기에만 저장)
- 한글(두벌식), 영어(QWERTY) 지원. 다른 언어를 추가할 수 있는 구조
- 단어 수준(글자 수, 받침, 쌍자음, 어휘 난도)과 속도를 프로필별로 설정
- 순수 교육용. 광고, 로그인, 결제 없음

## 개발

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 에 정적 파일 생성
npm test         # vitest (오토마타 + 화면 스모크 테스트)
```

## 모듈 계획

한컴타자연습 전 버전(도스 97 → 윈도우 2.0/96 → 2007 → 2010 → 2022)의 모듈을 조사해
기초부터 순서대로 만듭니다. 조사 내용은 [docs/modules.md](docs/modules.md)에 있습니다.

| 순서 | 모듈 | 상태 |
|---|---|---|
| 1 | 두벌식 입력 오토마타 (OS IME 미사용, `e.code` 기반) | 완료 |
| 2 | 자리 연습 (8구역, 손가락 색깔 가이드, 한글/영어) | 완료 |
| 3 | 클레이 사격 (글쇠 하나 쏘기 게임) | 예정 |
| 4 | 낱말 연습 (수준 1~5, 어휘 등급 + 글자 수·받침·Shift 자동 분석) | 완료 |
| 5 | 산성비 (낱말비 게임, 속도 1~5, 단계별 가속) | 완료 |
| 6 | 짧은 글 · 긴 글 연습 | 예정 |
| 7 | 설정(낱말 수준 · 속도 · 소리) · 기록 | 완료, 프로필·PWA 예정 |

## 설계 원칙

- **한글 입력은 직접 조합합니다.** 운영체제 IME에 의존하지 않고 물리 키 위치(`KeyboardEvent.code`)를 받아
  두벌식 오토마타로 글자를 만듭니다. 한/영 전환키를 아이가 신경 쓸 필요가 없고, 어떤 키를 눌러야 하는지
  화면 키보드에 정확히 표시할 수 있습니다.
- **언어는 데이터입니다.** 자판 배열, 자리 연습 단계, 낱말 목록은 `src/data/` 아래 언어별 파일로 분리합니다.
- **수준은 설정입니다.** 낱말에 난도 메타데이터(글자 수, 받침 유무, Shift 필요 여부, 어휘 등급)를 붙이고,
  프로필 설정으로 걸러서 냅니다. 어린이 모드와 어른 모드를 따로 만들지 않습니다.
- **빌드 결과는 어디서든 열립니다.** 호스팅된 URL은 물론, 단일 HTML 파일로도 동작하게 유지합니다
  (학교 네트워크 차단 대비).
